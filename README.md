# Waypoint — Employee Onboarding & Hiring Platform

Waypoint is a web platform that helps recruiters and hiring managers run the hiring pipeline and new-hire onboarding in one unified place.

## Features

- **Hiring Pipeline**: Track candidates through Kanban stages (`Applied` → `Screening` → `Interview` → `Offer` → `Hired`).
- **Interview & Scorecards**: Schedule interviews and capture structured interviewer scorecards and ratings.
- **Onboarding Journeys**: Manage structured onboarding checklists across phases (`Pre-boarding`, `Day 1`, `Week 1`, `Month 1`) grouped by owner (`IT`, `HR`, `Manager`, `New Hire`).
- **Recruiter & Manager Dashboard**: Dense metric overview featuring Quick Action tiles, Hiring Funnel bar charts, To-do items, Onboarding completion donut ring, and daily Schedule calendar.
- **Design System**: Soft lavender-grey canvas (`#F5F5FA`), indigo hero color (`#4F46E5`), 20px card radius, 12px element radius, locked 4-pair status pills, and Inter typography.

## Tech Stack

- **Core**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
